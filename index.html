Add a question set

Built-in banks are loaded from auxiliary JSON files. Import CSV, XLSX, or JSON for additional local question sets. For CSV and XLSX, use one row per question. Required: question, A, B, C, D, correct. Optional: topic, explanation, source.

Accepted headings include Question, A–D, Correct/Bonne réponse, Topic/Catégorie.

JSON: a question-set object with a questions array. Each question needs question text, four options, and a correct index from 0 to 3 (A to D). Existing sets are kept; importing a matching set ID creates a separate copy.

Delete question set?

This removes its questions, saved progress, and study choices from this browser on this device. This cannot be undone. Your original file is not deleted.
